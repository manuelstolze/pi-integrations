# Repository

`pi-integrations` contains independently published extensions for the Pi coding agent.

## Language

**Pi**:
The coding agent that the repository's extensions add behavior to.

**Extension**:
An npm package that adds behavior to Pi.

**Workspace**:
An extension package managed by the repository's shared npm workspace.

**Extension entry point**:
The file that Pi loads to start an extension.

**Skill**:
Instructions that guide Pi through a specific workflow and are loaded when needed.

**Jira integration**:
The extension for Jira issue search, details, comments, and description replacements approved in the conversation.

**Changeset**:
A release note that identifies changed packages and their required version increases.
