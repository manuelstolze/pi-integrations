# Changesets

This directory manages package versioning and changelogs via [Changesets](https://github.com/changesets/changesets).

Read the [full documentation](https://github.com/changesets/changesets/tree/main/docs) for more details on how to add changesets, and the [pre-1.0 workflow](https://github.com/changesets/changesets/blob/main/docs/prereleases.md) if you want to know how to add changesets for pre-1.0 packages.
